IBM Cognos Analytics – Nykaa Sales Analysis Practicals

📌 Project Overview

This project focuses on sales reporting and data visualization using IBM Cognos Analytics and the Nykaa Sales dataset. It includes six practical exercises covering report creation, data grouping, filtering, crosstab analysis, interactive prompts, and dashboard development.

The main objective is to transform Nykaa sales data into meaningful reports and visualizations that help understand sales performance and business trends.

🎯 Objectives

- Learn the IBM Cognos Analytics reporting environment.
- Create and format sales reports.
- Group sales data and calculate summary totals.
- Apply filters based on sales regions and dates.
- Build crosstab reports for product and regional analysis.
- Design interactive dashboards for sales insights.

🛠️ Tools and Technologies

- IBM Cognos Analytics – Reporting and dashboard creation
- Nykaa Sales Dataset – Sales data for analysis
- Business Intelligence (BI) – Data analysis and visualization

📚 Practicals Covered

Practical 1: Generate the First Nykaa Sales Report

- Created a basic list report using the Nykaa Sales dataset.
- Added Region, Product Category, and Sales Amount.
- Ran the report to display sales data.
- Saved the report for future use.

Practical 2: Build a Grouped Nykaa Sales List Report

- Added Region, Store Name, Product Category, Quantity, and Sales Amount.
- Grouped data by Region and Store Name.
- Formatted Sales Amount as currency.
- Added summary totals and a page header.

Practical 3: Filter Nykaa Sales by Region and Date

- Applied a Region filter to analyze a selected region.
- Added a date-range filter to focus on a reporting period.
- Combined filter conditions using AND.
- Converted the Region filter into a prompt for interactive analysis.

Practical 4: Build a Nykaa Region × Product Crosstab

- Created a crosstab with Region as rows and Product Category as columns.
- Added Sales Amount and Quantity as measures.
- Enabled row and column summary totals.
- Formatted sales figures as currency.

Practical 5: Build the Nykaa Sales Prompt Report

- Created a prompt page for Region and reporting date range.
- Added a cascading Store prompt.
- Linked prompts to the corresponding report filters.
- Tested the report using different regions and date ranges.

Practical 6: Build the Nykaa Customer Insights Dashboard

- Created a dashboard using available customer or sales data.
- Added a sales summary card.
- Created charts to analyze sales trends and product or customer segments.
- Added a Region filter to interact with dashboard visualizations.

📊 Key Learning Outcomes

- Creating and managing reports in IBM Cognos Analytics.
- Grouping, filtering, and aggregating sales data.
- Building crosstab reports with multiple measures.
- Designing interactive prompts and cascading filters.
- Creating dashboards with charts and summary cards.
- Interpreting sales data to identify business trends.
